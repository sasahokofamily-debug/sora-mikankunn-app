# sora-mikannkunn-app

みかんくんの **3Dレースゲーム** です。

## 今回の修正

- クリックゲームではなく、**レースゲーム** に変更
- みかんくんを **カートに乗せた** 3Dレースに変更
- 顔をつぶれにくいように、**顔パーツをテクスチャ化**
- 胸の **m** もテクスチャ化して見やすく変更
- 左右移動・障害物・アイテム・スコア・距離表示を追加

## 操作

- キーボード：`←` `→` または `A` `D`
- 画面のボタン：`ひだり` / `みぎ`

## ルール

- みかんアイテムを取ると **+10点**
- 障害物に 3 回ぶつかると終了
- 走った距離も表示されます

## 注意

- `three.js` は CDN から読み込んでいます。
- オフラインでは表示できない場合があります。
